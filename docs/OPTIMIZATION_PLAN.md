# 优化路线与当前选择

更新：2026-11-03。先诊断，再改动；当前证据见[实测记录](../experiments/EXP-20261103-01.md)及[历史图表](../visualizations/20261103/README.md)。

| 阶段 | 修改 | 已知结果 |
|---|---|---|
| 前期 | RoPE位置表、编译、KV预分配与精简 | 已有DCU公开四项对照，历史记录保留 |
| V1 | 单token解码跳过多余因果掩码处理 | 四项100%一致 |
| V2 → V2b | 将模型与下一token选择放入单步编译；修正编译卡点 | V2失败归档；V2b四项100%一致 |
| V3 | 矩阵乘自动调优，保持FP32 | 四项100%一致；保留监测对照版 |
| 组合版 | V2b基础上启用V3调优模式 | 同轮合计减少2.33%，两版各一轮，不认定稳定收益 |
| 精度方向 | 直接FP16、V4全部Linear权重半精度配置 | 一致性不足，当前配置不采用 |

当前优先完善组合版与V3对照的稳定性、请求独立性和复现材料，再决定最终入口。没有新证据不继续叠加大改动，不把所有低精度实现一概判死。

比较须使用相同负载与计时口径：先核一致率，再比较规定预热后的耗时。历史跨日图仅用于回顾；cProfile结果单列；编译失败不补造耗时。最终报告需写实际镜像、依赖、编译位置及完整命令。

本轮没有改官方基准或测试器，也未把候选替换为冻结的submission。正式计时Dynamo事件为0只是本次监测结论，不等于覆盖全部外部编译或主办方认证。
