# FP32 组合版 v89

组合已分别通过公开测试的 v8c 注意力核和 v9c RoPE/KV 核。单 token decode 先执行 RoPE/KV 写入，再对有效缓存执行分块注意力；原预填充、模型权重和官方工具保留。两个核本体不改，动态尺寸与步长保留运行时参数。

运行 `bash candidates/fp32_combo_v89/run_test.sh`。脚本自动进行源码指纹、直接核、组合小张量编译调用检查，然后执行官方四项测试、核对 4608/4608 一致和正式两类编译计数为零，成功或失败都保存结果并打包。核或模型失败不自动切换普通执行。

这是待 DCU 测试的组合候选，不能把单项收益相加。已通过的 v8c、v9c 原件不改；本地 CPU 替代核的集成检查不代表真实 Triton 或完整模型测试。
