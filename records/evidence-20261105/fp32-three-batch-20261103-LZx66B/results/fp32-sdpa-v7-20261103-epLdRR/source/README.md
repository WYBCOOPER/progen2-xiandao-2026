# fp32_sdpa_v7

SDPA 注意力：以 PyTorch SDPA 替代手写注意力路径；保留因果与外部掩码，需返回注意力权重或使用 head_mask 时保留原实现。

基于已通过 DCU 的 fp32_step_gemm_v23 独立修改，不包含输入投影融合，也不与本批另两项叠加。FP32、静态 KV、RoPE、矩阵乘调优与单步选择规则保留。初始化不读取请求输入、不预算请求相关 KV，编译在首次调用/预热时按需发生。

在现有 progen2_contest 目录执行：
```bash
bash candidates/fp32_sdpa_v7/run_test.sh
```

校验指纹后使用原官方测试工具跑四项，每次建立独立结果目录，记录版本、源码、成绩、日志、编译事件。结束或失败会打包，查看 RESULT_ARCHIVE。

四项 100% 一致、四次正式计时编译事件为 0 才通过；通过不等于提速，须与 v23 对比。SDPA 和 K 布局可能改变底层实现与舍入，若不一致保留负结果。没有静默关闭编译、降低精度或自动回退掩盖失败。

本地官方真实权重缩短生成、请求独立性及奇数长度检查通过；小模型 fullgraph 的 eager 后端捕获通过。未验证 DCU/Inductor 或完整官方长度，不预填收益。后续评审应保留 PyTorch/HIP/DTK/Triton 配置与这些源码。
