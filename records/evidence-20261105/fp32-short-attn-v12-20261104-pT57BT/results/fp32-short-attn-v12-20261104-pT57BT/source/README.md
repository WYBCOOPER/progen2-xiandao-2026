# v12：短上下文单核注意力

直接基于 v9c，未叠加 v10/v11。单 token decode 且有效 KV 长度不超过 128、无额外 mask 时，将 QK 乘积、缩放、softmax、PV 乘积合成一次 Triton 调用。长上下文和预填充保留父版路径，RoPE/KV 核及 FP32 保持原样。

与早先 v8c 的区别：不为短序列启动固定 16 份分区和二次合并，不分配部分结果/统计临时张量。128 是固定窗口上限；序列长度和所有步长都作为运行时参数，避免已遇到的符号 constexpr 错误。

注意力归约顺序会变化，小张量允许误差不能替代整模型完全一致检查。必须通过四项公开输出 4608/4608 一致和正式调用两类编译计数为零。长短分支的编译由官方预热覆盖；若正式调用编译，审查会失败。没有速度承诺。

运行 `bash candidates/fp32_short_attn_v12/run_test.sh`，自动检查、测试并打包成功或失败的结果。本版未修改官方测试器或基准。
